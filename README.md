
## Instalar como app (PWA)

Este projeto já vem preparado para ser "instalado" como aplicação, com ícone próprio, sem a barra de endereço do browser — mas isso só funciona quando o ficheiro está hospedado com HTTPS (não funciona bem abrindo o `.html` diretamente do seu computador).

### Passo a passo (usando GitHub Pages, grátis)

1. No repositório do GitHub, vá a **Settings → Pages**.
2. Em "Source", escolha o branch `main` e a pasta `/ (root)`. Guarde.
3. Ao fim de 1-2 minutos, o GitHub dá-lhe um link do tipo `https://SEU-UTILIZADOR.github.io/NOME-DO-REPOSITORIO/folha_rh_pro_2026.html`.
4. Abra esse link no telemóvel (Chrome/Android) ou no PC (Chrome/Edge).
5. **No telemóvel**: toque no menu (⋮) → "Adicionar ao ecrã principal" ou "Instalar app".
6. **No PC**: no Chrome/Edge, aparece um ícone de instalação (➕ ou ⊕) do lado direito da barra de endereço — clique e depois em "Instalar".

A partir daí, a app abre numa janela própria, com o ícone que criámos, sem parecer uma aba do Chrome.

**Nota importante:** o repositório GitHub tem de estar **público** para o GitHub Pages funcionar numa conta gratuita — com repositório privado, o Pages não gera o link (ou fica só acessível à sua conta). Se quiser manter os dados confidenciais mesmo assim, lembre-se de reativar o ecrã de bloqueio por código antes de tornar o repositório público.
